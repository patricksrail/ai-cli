## Install

```bash
npm install -g ai-cli
```

Or with other package managers:

```bash
bun add -g ai-cli
pnpm add -g ai-cli
yarn global add ai-cli
```

## Gateway access

Vercel AI Gateway remains the default. Set its key as before:

<Properties>
  <Property name="AI_GATEWAY_API_KEY" type="string">
    Vercel AI Gateway key. Provides access to all supported models through a
    single key.
  </Property>
</Properties>

Get a gateway key from the [Vercel AI Gateway dashboard](https://vercel.com/docs/ai-gateway).

```bash
export AI_GATEWAY_API_KEY="your-key"
```

To use Cloudflare AI Gateway provider-native routing instead:

1. [Enable gateway authentication](https://developers.cloudflare.com/ai-gateway/configuration/authentication/).
2. Add each provider credential under **Provider Keys** with the `default` alias. This is Cloudflare's [BYOK flow](https://developers.cloudflare.com/ai-gateway/configuration/bring-your-own-keys/).
3. Create a Cloudflare token with **AI Gateway Run** permission.
4. Configure ai-cli:

```bash
export AI_CLI_GATEWAY="cloudflare"
export CLOUDFLARE_ACCOUNT_ID="your-account-id"
export CLOUDFLARE_AI_GATEWAY_ID="default"
export CLOUDFLARE_AI_GATEWAY_TOKEN="your-ai-gateway-run-token"
```

If `CLOUDFLARE_AI_GATEWAY_TOKEN` is unset, ai-cli falls back to `CLOUDFLARE_API_TOKEN`; that token must also grant **AI Gateway Run**. Do not export provider keys for Cloudflare mode. ai-cli removes provider authorization headers and Cloudflare injects the stored BYOK key.

Add this to your shell profile (`~/.zshrc`, `~/.bashrc`, etc.) to persist across sessions.

## Verify

```bash
ai text "hello"
```

If you see generated text, you're ready.
