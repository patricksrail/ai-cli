## Install

```bash
git clone https://github.com/patricksrail/ai-cli.git
cd ai-cli
bun install
bun run --cwd packages/ai-cli build
bun link --cwd packages/ai-cli
export PATH="$HOME/.bun/bin:$PATH"
```

## Gateway access

Cloudflare AI Gateway is the default in this fork. Configure the authenticated `ai-cli` gateway once:

1. [Enable gateway authentication](https://developers.cloudflare.com/ai-gateway/configuration/authentication/).
2. Add each provider credential under **Provider Keys** with the `default` alias. This is Cloudflare's [BYOK flow](https://developers.cloudflare.com/ai-gateway/configuration/bring-your-own-keys/).
3. Create a Cloudflare token with **AI Gateway Run** permission.
4. Configure ai-cli:

<Properties>
  <Property name="CLOUDFLARE_ACCOUNT_ID" type="string">
    Cloudflare account ID.
  </Property>
  <Property name="CLOUDFLARE_AI_GATEWAY_TOKEN" type="string">
    Cloudflare token with AI Gateway Run permission.
  </Property>
</Properties>

```bash
export CLOUDFLARE_ACCOUNT_ID="your-account-id"
export CLOUDFLARE_AI_GATEWAY_TOKEN="your-ai-gateway-run-token"
```

Cloudflare and gateway ID `ai-cli` are the defaults. Set `CLOUDFLARE_AI_GATEWAY_ID` only to select a different gateway. If `CLOUDFLARE_AI_GATEWAY_TOKEN` is unset, ai-cli falls back to `CLOUDFLARE_API_TOKEN`; either token must grant **AI Gateway Run**. Do not export provider keys: ai-cli removes provider authorization headers and Cloudflare injects the stored BYOK key.

To use the upstream Vercel AI Gateway instead:

```bash
export AI_CLI_GATEWAY="vercel"
export AI_GATEWAY_API_KEY="your-vercel-gateway-key"
```

Add this to your shell profile (`~/.zshrc`, `~/.bashrc`, etc.) to persist across sessions.

## Verify

```bash
ai text "hello"
```

If you see generated text, you're ready.

## Requirements

<Properties>
  <Property name="Bun" type="1.0+" required>
    ai-cli runs with Bun. Install from bun.sh.
  </Property>
  <Property name="API key" type="string" required>

    stored through BYOK, or a Vercel key in explicit Vercel mode.
