## Install

```bash
npm install -g ai-cli
```

Or with other package managers:

```bash
bun add -g ai-cli
pnpm add -g ai-cli
yarn global add ai-cli
```

## Gateway access

Vercel AI Gateway remains the default. Set its key as before:

<Properties>
  <Property name="AI_GATEWAY_API_KEY" type="string">
    Vercel AI Gateway key. Provides access to all supported models through a single key.
  </Property>
  <Property name="OPENAI_API_KEY" type="string">
    Provider-specific key. Use if you only need OpenAI models.
  </Property>
</Properties>

Get a gateway key from the [Vercel AI Gateway dashboard](https://vercel.com/docs/ai-gateway).

```bash
export AI_GATEWAY_API_KEY="your-key"
```

To use Cloudflare AI Gateway provider-native routing instead:

```bash
export AI_CLI_GATEWAY="cloudflare"
export CLOUDFLARE_ACCOUNT_ID="your-account-id"
export CLOUDFLARE_AI_GATEWAY_ID="default"
export OPENAI_API_KEY="your-openai-key"
```

Add `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, or `REPLICATE_API_TOKEN` for those providers. If the Cloudflare gateway has authentication enabled, also set `CLOUDFLARE_API_TOKEN`.

Add this to your shell profile (`~/.zshrc`, `~/.bashrc`, etc.) to persist across sessions.

## Verify

```bash
ai text "hello"
```

If you see generated text, you're ready.

    A Vercel AI Gateway key, or Cloudflare configuration plus at least one provider key.
  </Property>
