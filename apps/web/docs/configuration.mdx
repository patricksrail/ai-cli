ai-cli uses environment variables and per-command flags. Model preferences can also be loaded from an optional JSON file.

## Environment variables

<Properties>
  <Property name="AI_CLI_GATEWAY" type="vercel | cloudflare">
    Gateway backend. Defaults to `cloudflare`.
  </Property>
  <Property name="AI_CLI_MODEL_PREFERENCES" type="path">
    Optional JSON override for defaults, best, cheapest, and bestFree model preferences. Bundled choices live in src/fork/model-preferences.json and include preferred aliases and ordered fallbacks.
  </Property>
  <Property name="AI_CLI_PROVIDERS" type="string">
    Optional comma-separated stored provider inventory for Run-only tokens. Otherwise discovery reads Cloudflare Provider Keys using a token with AI Gateway Read permission.
  </Property>
  <Property name="AI_GATEWAY_API_KEY" type="string">
    Vercel AI Gateway API key. Provides access to all supported models.
  </Property>
  <Property name="CLOUDFLARE_ACCOUNT_ID" type="string">
    Cloudflare account ID. Required on the default Cloudflare backend.
  </Property>
  <Property name="CLOUDFLARE_AI_GATEWAY_ID" type="string">
    Cloudflare AI Gateway name. Defaults to `ai-cli`.
  </Property>
  <Property name="CLOUDFLARE_AI_GATEWAY_TOKEN" type="string">
    Preferred Cloudflare authentication token. Required in Cloudflare mode and
    must grant AI Gateway Run. Automatic provider discovery also uses this token for AI Gateway Read when supplied.
  </Property>
  <Property name="CLOUDFLARE_API_TOKEN" type="string">
    Fallback Cloudflare token when `CLOUDFLARE_AI_GATEWAY_TOKEN` is unset. It
    must grant AI Gateway Run.
  </Property>
  <Property name="AI_CLI_TEXT_MODEL" type="string">
    Default text model. Overrides `google/gemini-3.8-flash`.
  </Property>
  <Property name="AI_CLI_IMAGE_MODEL" type="string">
    Default image model. Overrides `fal/fal-ai/flux/schnell`.
  </Property>
  <Property name="AI_CLI_VIDEO_MODEL" type="string">
    Default video model. Overrides `replicate/prunaai/p-video`.
  </Property>
  <Property name="AI_CLI_SPEECH_MODEL" type="string">
    Default speech model. Overrides `fal/fal-ai/minimax/speech-02-turbo`.
  </Property>
  <Property name="AI_CLI_TRANSCRIPTION_MODEL" type="string">
    Default transcription model. Overrides `fal/fal-ai/wizper`.
  </Property>
  <Property name="AI_CLI_OUTPUT_DIR" type="path">
    Default output directory for generated files.
  </Property>
  <Property name="AI_CLI_PREVIEW" type="0 | 1">
    `1` forces inline preview on, `0` disables it.
  </Property>
  <Property name="NO_COLOR" type="any">
    Disable ANSI color output.
  </Property>
  <Property name="FORCE_COLOR" type="any">
    Force color output even when not a TTY.
  </Property>
</Properties>

## Precedence

- `--gateway` overrides `AI_CLI_GATEWAY`.
- `--provider` selects a Cloudflare host; `-m` then takes its native model ID, or selection flags restrict candidates to that host.

- `--best`, `--free`, or `--cheapest` selects a model independently of the normal default; `--free -m <full-id>` also validates a specific free route.
- `-m` flag always takes priority over `AI_CLI_*_MODEL` env vars.
- `-o` flag always takes priority over `AI_CLI_OUTPUT_DIR`.
- `--no-preview` takes priority over `AI_CLI_PREVIEW`.
- `CLOUDFLARE_AI_GATEWAY_TOKEN` takes priority over `CLOUDFLARE_API_TOKEN`.

## Example shell profile

```bash
export CLOUDFLARE_ACCOUNT_ID="your-account-id"
export CLOUDFLARE_AI_GATEWAY_TOKEN="your-ai-gateway-run-token"
export AI_CLI_TEXT_MODEL="openrouter/anthropic/claude-sonnet-4"
export AI_CLI_IMAGE_MODEL="fal/fal-ai/flux/schnell"
export AI_CLI_OUTPUT_DIR="$HOME/ai-output"
```

Vercel alternative:

```bash
export AI_CLI_GATEWAY="vercel"
export AI_GATEWAY_API_KEY="your-vercel-gateway-key"
```

The default Cloudflare backend requires an [authenticated gateway](https://developers.cloudflare.com/ai-gateway/configuration/authentication/). Store OpenAI, Google AI Studio, OpenRouter, Replicate, and Fal credentials in the gateway's **Provider Keys** page with the `default` alias. ai-cli does not read or forward local provider keys or provider authorization headers.

Patrick’s local Mac launcher loads Cloudflare auth defaults from the existing canonical local setup and preserves explicit environment overrides. The portable npm CLI still requires configured Cloudflare environment variables; it does not assume a user-specific credential path.

Workers AI integration is disabled in the provider registry by choice. Its retained adapter uses `CLOUDFLARE_API_TOKEN` with Workers AI Metadata Read for catalogs and Workers AI Read for inference. It verifies gateway spending caps for ordinary generation, or account subscriptions for free-only use. A gateway Run-only token is insufficient. Prepaid billing is refused; the adapter never changes plans or buys credits.
